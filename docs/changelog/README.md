# Changelog

本目录按日期记录项目开发过程中的变更。文件名使用 `YYYY-MM-DD.md`，同一天的多次变更追加到同一个文件。

## 记录要求

- 每次完成一个任务、切片或重要文档变更后，更新当天的 changelog。
- 没有当天文件时创建 `YYYY-MM-DD.md`。
- 每条记录至少包含：变更摘要、影响文档、验证方式、遗留问题。
- 全局文档发生变化时，必须同步更新对应文档，并在当天 changelog 中记录。
- 不记录无意义的过程噪音；只记录会影响后续开发判断的变更。

## 修改规则

- 只能修改当天 `YYYY-MM-DD.md`；过往日期的 changelog 文件一旦跨天即只读，不允许再修改。
- 当天文件可以合并重复条目、删除噪音，但不能丢失关键结论、验证方式和遗留问题。
- 如果需要纠正历史记录，在当天文件中追加更正说明，不回改旧文件。

## 模板

```markdown
# YYYY-MM-DD

## HH:MM 变更标题

- 变更摘要：
- 影响文档：
- 验证方式：
- 遗留问题：
```
